# QA Automation Framework – Playwright / Cypress / API / Performance

This repository showcases my practical experience in software test automation using modern tools and frameworks.  
It includes real-world test examples built with **Playwright**, **Cypress**, **Postman**, and **JMeter**, covering different layers of quality assurance.

---

## 🚀 Tech Stack
- **Playwright (TypeScript)** – End-to-end UI automation
- **Cypress** Component and regression testing for web apps
- **Postman** – REST API automation & collection runners
- **JMeter** – Performance and load testing

---

## 🧩 Project Structure

automation-elhb/

│

├── playwright/ → UI automation using Playwright (TypeScript)

├── cypress/ → UI automation using Cypress

├── postman/ → API tests & collections

└── jmeter/ → Performance testing scripts

- Designed using **Page Object Model (POM)**  
- **Reusable test utilities** and fixtures  
- Supports **parallel execution** and multi-browser runs

- **Clear reporting** with Playwright HTML reports  
- CI‑ready structure (works with GitHub Actions or Jenkins)
